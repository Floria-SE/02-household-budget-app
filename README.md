# 家計簿アプリ

## 概要
収入と支出を項目ごとに記録し、合計金額や収支を確認できる家計簿アプリです。

## 機能
-収入、支出の金額を項目と共に記録する
-記録した項目、金額の修正
-記録した収入、支出の表示

## 学習したこと
-`def`：関数を定義する
-引数：関数に値を渡す
-`return`：関数から値を返す
-リスト：複数のデータをまとめて管理する
-辞書：関連データをまとめて管理する
-`for i in ~`：~から値を順に取り出す
-`enumerate`：リストからインデックス番号と値ををれぞれ取り出す

## 工夫したこと
-同じ処理を何度も使わなくていいように関数を定義した

## 実行方法
1. `main.py`をVS Codeで開く
2. 右上の三角マーク（実行ボタン）を押す
3. ターミナルの表示に従って入力する
